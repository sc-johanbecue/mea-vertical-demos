# CMS naming taxonomy

## Site chrome

`TopBar`, `Header`, `Navigation`, `Breadcrumb`, `CookieBanner`, `Footer`, `SearchOverlay`, `LanguageSelector`, `LoginLink`, `UtilityNavigation`

## Hero / page intro

`HeroBanner`, `HeroCarousel`, `HeroSplit`, `PageTitleHeader`, `LandingHero`, `CampaignHero`, `VideoHero`

## Editorial sections

`RichTextSection`, `RichTextImageBlock`, `ImageTextBlock`, `TextImageBlock`, `QuoteBlock`, `CtaBlock`, `BackgroundImageCtaBlock`, `FeatureBlock`, `TabbedContent`, `AccordionSection`

## Grids / lists

`VerticalTeaserGrid`, `HorizontalTeaserGrid`, `CardGrid`, `LinkGrid`, `IconLinkGrid`, `NewsList`, `EventList`, `ProductGrid`, `ProfileGrid`, `LogoGrid`, `DownloadList`, `RelatedLinks`

## Repeating child items

`VerticalTeaserCard`, `HorizontalTeaserCard`, `LinkCard`, `IconLinkCard`, `StatsItem`, `LogoItem`, `NewsCard`, `EventCard`, `ProductCard`, `ProfileCard`, `DownloadItem`, `FooterLinkItem`, `HeroSlide`

## Naming formula

```txt
{Purpose}{Layout}{ComponentType}
```

Examples:

- `ExploreMoreVerticalTeaserGrid`
- `SustainabilityStatsBar`
- `PartnerLogoGrid`
- `ArticleRelatedLinks`
- `ContactCtaBlock`

Prefer reusable CMS names. Add business context only when it prevents ambiguity.
