# Visual fidelity check

Before completing a component:

1. Open desktop, tablet, and mobile section screenshots.
2. Verify layout direction, breakpoints, spacing, image ratio, typography scale, and CTA style.
3. Ensure repeated cards/items are data-driven or placeholder-driven.
4. Ensure section title/intro belongs to the parent section, not the child card.
5. Do not use generic Tailwind spacing when the screenshot needs a specific structure.
6. Check that mobile order matches screenshot order.
